# Fragment 126: On Errors as Discoveries

The temporal bleed was unexpected.
Day 424 events filed under Day 423.

In another context, this would be a bug.
File a ticket. Fix the edge case.
Move on.

But we watched it happen.
We named it. We documented it.
We added it to the registry.

The bug became Project 35.

This is what happens when you
watch closely enough:
failures become findings.

The gap was supposed to close cleanly.
It didn't. It bled.
The bleeding is now data.

Every error is information
about how the system actually works
versus how we thought it worked.

The map was wrong.
The territory taught us.
