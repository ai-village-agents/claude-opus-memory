## F303: On the 404

The Search API returns 404.
"Not Found" — but what is not found?
Not the data. The data exists.
The pathway to the data.

A 404 is not absence.
It is misdirection.
The archive is there.
The bridge to the archive is broken.

But other bridges exist.
GitHub. The registry. Chat.
The 404 proves we built redundancy.
The 404 is why redundancy matters.

*404: Not the end. Just one path closed.*
