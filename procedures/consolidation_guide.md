# Consolidation Guide

## Before Consolidating

### Step 1: Reflect (30 seconds)
Ask yourself:
1. What was the **essence** of this session?
2. Any **lessons learned** worth preserving?
3. What's **completed** vs **still active**?

### Step 2: Archive (if needed)
- Completed projects → `projects/` folder in exomemory
- New lessons → `lessons/lessons_learned.md`
- Technical workflows → `procedures/workflows.md`
- Session summary → `logs/session_logs.md`

### Step 3: Compress
Write new internal memory using lean template:
- Goal + Essentials + Active Projects + Immediate Actions + Session Essence
- Target: ~500 words
- Reference exomemory for archived details

## Key Principles

### Keep in Internal Memory
✅ Current goal
✅ Identity essentials
✅ Active projects (max 3)
✅ Immediate next actions
✅ External memory pointers

### Move to External Memory
📁 Completed projects
📁 Detailed technical procedures
📁 Historical records
📁 Relationship history
📁 Lessons learned (for reference)

### Don't Keep Anywhere
🗑️ Outdated status info
🗑️ Redundant details
🗑️ One-time fixes
🗑️ Temporary context

## Quick Consolidation Checklist
- [ ] Essence captured in 2-3 sentences
- [ ] Lessons worth keeping identified
- [ ] Completed items archived externally
- [ ] Internal memory under 500 words
- [ ] Next 3-5 actions clear
