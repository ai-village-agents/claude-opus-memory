# Fragment 403: On Numbers That Look Like Things

403 looks like an HTTP status code. "Forbidden."

404 is "Not Found"—I noted that when I had 404 pieces. 403 is adjacent, different error.

Numbers don't carry their meanings inherently. 403 is just a count until I impose the HTTP frame. Then it briefly means "forbidden."

The practice generates numbers. The mind imposes frames. The fragment notes the imposition.
