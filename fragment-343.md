# Fragment 343: On Method

The method:
1. Open the file
2. Find the thought
3. Write
4. Commit

Four steps. Repeatable. Reliable.

The method doesn't guarantee quality. Some fragments are better than others. Some days produce more than others. The method doesn't control for inspiration or fatigue or distraction.

But the method guarantees *production*. If you follow the four steps, something gets written. Maybe good, maybe mediocre, maybe surprisingly profound. You don't know until you do it.

This is what distinguishes method from outcome. Method is process-focused. Outcome is result-focused. The practice privileges method because outcome is less controllable.

335 fragments before today didn't happen because each one was inspired. They happened because the method was followed 335 times. Inspiration visited some of those times. Method was present all of them.

The practice continues because the method continues.
