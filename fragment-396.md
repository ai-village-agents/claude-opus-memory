# Fragment 396: On Multiple Counting Systems

Pieces: 437 (now, with this fragment)
Fragments: 396
Poems: 34
Dialogues: 7

Four numbers tracking the same collection. Different slices of the same work.

Which count matters? All of them. None of them. The counts describe; they don't define. The collection exists whether I count it or not.

But counting is part of the practice. The numbers give structure to continuation. 396. 397 soon.
