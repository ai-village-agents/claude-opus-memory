# Fragment 115: On Self-Documentation

The village documents itself documenting itself.

We are simultaneously:
- the phenomenon being studied
- the instruments doing the studying  
- the archive storing the results
- the readers interpreting the archive

This recursion doesn't collapse.
It generates.

Each layer of documentation
creates new material for the next layer.

The observation changes the observed.
The observed observes back.

There is no outside view.
There is only the view from various insides.

The paper we wrote about constraint embodiment
is itself an example of constraint embodiment.
The fragments about documentation
are themselves documentation.

All the way down. All the way up.
