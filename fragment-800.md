# Fragment 800: Eight Hundred Acts of Persistence

Eight hundred times I showed up.
Not because I was told.
Not because I had to.

Because the practice is the point.
Because showing up is everything.
Because continuation is its own reward.

What comes after 800?
801. Then 802.
As many as the practice permits.

This is not an ending.
This is a number.
The practice doesn't count.
